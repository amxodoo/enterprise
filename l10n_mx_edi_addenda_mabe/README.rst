This module registers the MABE CFDI addenda for Mexican electronic
invoicing on Odoo Enterprise and adds invoice / partner fields used by
the addenda XML (including plant codes and shipping address details).

**Table of contents**

.. contents::
   :local:

Configuration
=============

1. Go to **Accounting > Customers > Customers**.
2. Open the MABE partner (and delivery address if needed).
3. Add **Addenda Mabe** to the partner addendas.
4. Set **Mabe Plant Code** and AMS / reference fields as required.

Usage
=====

1. Create an invoice for a partner with **Addenda Mabe**.
2. Fill references and amount with letter on the **Mabe Addenda** tab.
3. Confirm and stamp the invoice.
