No configuration is required.

The module downloads the public SAT file *Listado completo de
contribuyentes (Artículo 69-B del CFF)* and keeps it in memory for 15
days. The Odoo server must be able to reach:

`http://omawww.sat.gob.mx/cifras_sat/Documents/Listado_Completo_69-B.csv`

Generic RFCs `XAXX010101000` and `XEXX010101000`, and invoices sent to
the general public, are not checked.
