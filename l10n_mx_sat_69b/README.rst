Download the public SAT list of taxpayers under article 69-B of the CFF
and look up an RFC.

The result includes the taxpayer name, the SAT status (Presunto,
Definitivo, Desvirtuado or Sentencia Favorable) and the official
reference (número y fecha de oficio). The list is kept in memory for 15
days.

This module does not block invoices. Other modules use it to check
customers or vendors.

Configuration
=============

No configuration is required.

The Odoo server must be able to reach:

``http://omawww.sat.gob.mx/cifras_sat/Documents/Listado_Completo_69-B.csv``

Usage
=====

Other modules call ``lookup_taxpayer`` with an RFC.

The call returns the name, SAT status and official reference when the
RFC is on the list. It returns an empty result when the RFC is not
listed or when it is a generic invoice RFC (``XAXX010101000``,
``XEXX010101000``).
